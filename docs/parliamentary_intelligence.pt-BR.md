# Inteligência Parlamentar

🇺🇸 Documento técnico — Inteligência Parlamentar, Marts Analíticos e Análises Políticas

---

# Visão Geral

Este documento descreve a camada analítica avançada implementada no projeto `camara-data-pipeline`.

A arquitetura analítica foi projetada para transformar dados parlamentares brutos em produtos analíticos reutilizáveis capazes de apoiar:

* análises políticas;
* inteligência parlamentar;
* análise financeira;
* análise comportamental;
* monitoramento de transparência;
* análise de alinhamento de votações;
* análise de despesas;
* inteligência partidária;
* detecção de anomalias.

---

# Visão Analítica

O projeto vai além do processamento ETL tradicional ao implementar uma camada de inteligência parlamentar focada em exploração analítica e cenários de apoio à decisão.

A arquitetura analítica combina:

* modelagem dimensional;
* marts analíticos;
* dimensões reutilizáveis;
* views analíticas;
* indicadores parlamentares;
* analytics comportamentais;
* inteligência financeira;
* métricas operacionais.

# Camada Analítica Gold

A camada Gold materializa entidades dimensionais e marts analíticos.

## Principais características

* modelagem star schema;
* dimensões conformadas;
* tabelas fato reutilizáveis;
* escalabilidade analítica;
* surrogate keys;
* estruturas Delta otimizadas.

# Detecção de Anomalias Z-Score

O projeto implementa detecção estatística de anomalias utilizando análise z-score.

## Níveis de classificação

| Classificação | Significado |
|---|---|
| Comportamento Esperado | Comportamento normal de despesas |
| Possível Anomalia | Desvio moderado |
| Anomalia Extrema | Desvio significativo |
| Anomalia Crítica | Desvio analítico de alto risco |
